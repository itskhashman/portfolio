# Portfolio Website

This is a personal portfolio website showcasing my projects, skills, and experience as a Front-End Developer.  
The project is built with **Angular**, **Bootstrap**, **SCSS**, and other modern web technologies.

## Features

- Responsive design using Bootstrap
- Interactive project showcase
- Smooth animations and UI enhancements
- Contact form integration

## Tech Stack

- **Framework:** Angular 18
- **Styling:** SCSS, Bootstrap
- **Routing:** Angular Router
- **Carousel/Slider:** ngx-splide
- **Animations:** Angular Animations
- **Version Control:** Git & GitHub Pages deployment

## Development Server

Run `ng serve` for a development server. Navigate to `http://localhost:4200/`.  
The app will automatically reload if you change any of the source files.

```bash
ng serve
